# BongoDSH 0.2.4

页面与桌面设置精简，滑块样式统一。安装包包含最新角色素材和全局键盘设置保存功能。

## 更新

- 删除设置中的介绍语、重复动作说明和常态定位提示，保留错误与权限提示。
- 角色大小、手部幅度、身体幅度统一使用细轨道、圆形手柄和 24 px 操作区域。
- 保留六款精修角色、独立双手、输入框紧贴定位、拖出 DSH 和跨程序窗口吸附。
- 手部与身体幅度独立调整，页面与桌面同步角色、大小、暂停和幅度。
- 全局键盘选择保存在本机，重启 DSH 或重新拖出后自动恢复。
- 插件、Rust 程序和 macOS App 版本统一为 0.2.4。

## 下载与安装

| 附件 | 用途 |
| --- | --- |
| `dsh-bongodsh-0.2.4-darwin-arm64.tgz` | macOS Apple Silicon 完整包，含桌面组件 |
| `dsh-bongodsh-0.2.4-web.tgz` | 通用 DSH 页面包，不含桌面组件 |
| `SHA256SUMS.txt` | 两个安装包的 SHA-256 校验值 |

两个安装包均包含六款角色的全部素材。完整包的页面、桌面程序与素材均从本次源码重新构建；PNG 与原文件保持字节一致。GitHub 自动生成的 Source code 压缩包是源码，不是插件安装包。

需要 DSH `>=0.2.1-rc.5`，实测版本为 `0.2.1-rc.5`。在「插件 → 添加插件」中填写下载文件的绝对路径，安装后启用；也可以使用命令行：

```sh
dsh plugin --profile web add /absolute/path/dsh-bongodsh-0.2.4-darwin-arm64.tgz
```

页面包替换对应文件名。profile 按自己的实例调整，安装或升级后重启 DSH 并刷新页面。macOS 完整包无需 Rust，当前没有 Windows 或 Intel Mac 桌面预编译包。

跨应用打字需在桌面角色右键设置的「桌面选项」中开启全局键盘。macOS 首次使用需授予系统输入监控权限，此后设置会自动恢复。安装包没有 Developer ID 签名或公证。

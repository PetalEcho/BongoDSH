# BongoDSH 0.2.5

## 更新

- 使用 Rust 1.99.1 重建三平台桌面包。

## 下载与安装

| 附件 | 用途 |
| --- | --- |
| [dsh-bongodsh-0.2.5-darwin-arm64.tgz](https://github.com/PetalEcho/BongoDSH/releases/download/v0.2.5/dsh-bongodsh-0.2.5-darwin-arm64.tgz) | macOS Apple Silicon 完整包 |
| [dsh-bongodsh-0.2.5-darwin-x64.tgz](https://github.com/PetalEcho/BongoDSH/releases/download/v0.2.5/dsh-bongodsh-0.2.5-darwin-x64.tgz) | macOS Intel 完整包 |
| [dsh-bongodsh-0.2.5-win32-x64.tgz](https://github.com/PetalEcho/BongoDSH/releases/download/v0.2.5/dsh-bongodsh-0.2.5-win32-x64.tgz) | Windows x64 完整包 |

在 DSH「插件 → 添加插件」粘贴对应链接并启用，无需下载后本地导入。

跨应用打字需在桌面角色右键设置的「桌面选项」中开启全局键盘。macOS 首次使用需授予系统输入监控权限，此后设置会自动恢复。

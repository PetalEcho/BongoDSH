# BongoDSH 0.2.5

## 更新

- 删除设置中的介绍语、重复动作说明和常态定位提示，保留错误与权限提示。
- 角色大小、手部幅度、身体幅度统一使用细轨道、圆形手柄和 24 px 操作区域。
- 保留六款精修角色、独立双手、输入框紧贴定位、拖出 DSH 和跨程序窗口吸附。
- 手部与身体幅度独立调整，页面与桌面同步角色、大小、暂停和幅度。
- 全局键盘选择保存在本机，重启 DSH 或重新拖出后自动恢复。
- 插件、Rust 程序和 macOS App 版本统一为 0.2.5。
- 使用 Rust 1.99.1 重建三平台桌面包。

在 DSH「插件 → 添加插件」粘贴对应链接并启用，无需下载后本地导入。

Intel Mac 和 Windows x64 界面尚未实机验证。

跨应用打字需在桌面角色右键设置的「桌面选项」中开启全局键盘。macOS 首次使用需授予系统输入监控权限，此后设置会自动恢复。macOS 安装包未经过 Developer ID 签名和公证。

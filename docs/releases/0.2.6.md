# BongoDSH 0.2.6

## 更新

- 页面角色仅在对话 Tab 显示。切到轨迹、上下文、编队或插件页时隐藏，返回对话后恢复；自由放置模式也遵循此规则。
- 页面和桌面设置窗口均可拖动标题栏移动。页面面板限制在可见区域内，并在本次页面会话中保留位置。
- 桌面「吸附窗口」输入仅响应当前吸附且获得焦点的窗口；全局模式响应所有应用。新增监听连接状态和收到有效按键的提示，权限失败时保留用户选择。
- 缩小桌面角色周围的透明留白，保留完整动作空间和从页面拖出的抓取位置；拖近可吸附窗口时显示边缘提示。
- 同步基础大肥鱼、水手鱼、睡衣鱼、魔法师鱼和克劳德的最新素材，页面、拖出桌面和独立桌面版共用身体与双手图层。
- macOS 完整应用包增加本地临时签名和校验，未经过 Developer ID 签名或公证。

## 下载与安装

| 附件 | 用途 |
| --- | --- |
| [macOS Apple Silicon 完整包](https://github.com/PetalEcho/BongoDSH/releases/download/v0.2.6/dsh-bongodsh-0.2.6-darwin-arm64.tgz) | 页面插件与 Apple Silicon 桌面程序 |
| [macOS Intel 完整包](https://github.com/PetalEcho/BongoDSH/releases/download/v0.2.6/dsh-bongodsh-0.2.6-darwin-x64.tgz) | 页面插件与 Intel 桌面程序 |
| [Windows x64 完整包](https://github.com/PetalEcho/BongoDSH/releases/download/v0.2.6/dsh-bongodsh-0.2.6-win32-x64.tgz) | 页面插件与 Windows 桌面程序 |
| [通用页面包](https://github.com/PetalEcho/BongoDSH/releases/download/v0.2.6/dsh-bongodsh-0.2.6-web.tgz) | 仅页面模式，不含桌面程序 |
| [SHA256 校验和](https://github.com/PetalEcho/BongoDSH/releases/download/v0.2.6/SHA256SUMS.txt) | 核对下载文件 |

在 DSH「插件 → 添加插件」中粘贴对应完整包链接并启用。升级后重启 DSH。命令行安装时，profile 需与实际实例一致，DSH 桌面应用使用 `desktop`。

macOS 全局键盘需由用户主动开启输入监控权限，吸附窗口输入另需辅助功能权限。恢复已保存的模式不会自动申请权限。程序只处理物理按键，不读取、记录或上传输入文字。

## 验证范围

macOS Apple Silicon 已在真实 DSH 中安装并验证：非对话 Tab 隐藏、返回对话恢复、自由放置模式显隐、页面和原生设置窗口拖动、拖出桌面及返回 DSH。Rust 格式、Clippy、本地回归测试、release 构建、模拟输入 demo，以及插件构建和产物一致性检查通过。

三个平台的发布包均由 CI 校验并构建。Intel Mac 与 Windows 的界面、权限、多显示器及 DPI 行为尚未实机验证。本地测试文件不随源码提交，CI 的测试步骤只运行仓库中可用的目标。

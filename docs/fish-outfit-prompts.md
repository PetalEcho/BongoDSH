# 三套线稿的实际提示词

生成方式为内置 imagegen。换装以 `assets/concepts/fish-maid-lineart.png` 为基准，手部只参考用户指定的 `hand-bounce.png` 外形。

最终文件按身体、左手、右手分开保存。初稿图集仅用于生成过程，不作为最终交付，也不保留在项目中。身体由内置编辑移除图集双手后单独输出；手部只生成一次，再原样复制到各套的左右手文件，没有程序重绘或像素修改。

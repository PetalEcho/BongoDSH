# DSH 插件验证记录

记录实际执行的平台和检查，不代表所有平台均已实机验证。本地测试按项目约定不随源码提交。

## 0.2.5

2026-11-03，构建工具链统一为 Rust 1.99.1，插件与桌面程序版本统一为 0.2.5。Apple Silicon 通过格式检查、Clippy、27 项本地 Rust 回归、release 构建、命令行模拟和客户端产物一致性检查；功能与十二个 PNG 沿用已验证的 0.2.4，仅明确九处浮点字面量的类型以适配新版 Clippy。

Windows x64 与 Intel Mac 在各自的 GitHub Actions runner 上完成格式检查、Clippy、可用目标测试、release 打包、版本校验和命令行模拟，见[构建记录](https://github.com/PetalEcho/BongoDSH/actions/runs/41591468550)。CI 不包含忽略的本地回归用例，两个平台的界面尚未实机验证。

Release 仅提供三个平台的完整桌面包。DSH 通过对应附件的 HTTPS 链接安装，操作与链接见 [README](../README.md)。

三个已发布附件的 SHA-256 均与本地核验产物一致。各包版本、平台架构、客户端和十二个 PNG 均已核对；Intel Mac 和 Windows 包相较 CI 原件仅同步最终 README，程序字节不变。包内不含测试、用户设置或其他平台的原生程序。

本机 DSH 已移除原本的本地目录来源，通过 Release 链接安装并启用 0.2.5。重启 DSH 后，确认子进程来自 profile 的 `node_modules/dsh-bongodsh`；魔法师装、160 px、手部与身体 100% 均保留，原生设置自动选中全局键盘并显示已连接。未更改系统权限。

## 0.2.4

2026-11-03，页面和原生设置文案精简，三条滑块改为 4 px 轨道、约 14 px 圆柄与 24 px 操作区。59 项 Node 回归、27 项 Rust 回归、格式检查、macOS / Windows Clippy、release 构建和命令行模拟通过。

Chrome 预览验证了滑块键盘极值及填充同步。真实 macOS DSH 已加载新版页面和原生组件，确认精简设置、独立幅度的 0 / 200% 调整、恢复 100% 和返回 DSH。原生面板自动恢复全局键盘，并显示已连接。

发布命令统一校验插件与 Rust 版本，重新生成页面、校验十二个内嵌 PNG 并构建桌面程序，分离通用页面包与 macOS arm64 完整包。Windows 仅完成目标检查；Firefox、Intel Mac 与 Windows 界面未实机验证。macOS 包没有 Developer ID 签名或公证。

## 历史版本

2026-11-02 在 macOS Apple Silicon / Chrome 完成旧版 14 项 Node 回归检查，包含模拟 Windows CRLF 检出后的产物校验，并验证设置保存、拖动保留输入焦点、输入框隐藏回退、重建、卸载和重复加载。另将旧版打包文件离线安装到临时目录，验证包导出，并用本机 DSH `0.2.1-rc.5` 的实际模块加载器完成导入。

2026-11-03 完成 0.1.1 构建、语法与产物一致性检查、16 项 Node 回归检查和打包清单检查。新增覆盖旧设置迁移、角色切换时清除旧手部图层，以及七个内嵌 PNG 解码后与原文件字节一致。在真实 macOS DSH 的插件页完成本地目录安装与启用，确认组件运行中，逐个切换全部六个角色，并检查聊天页和新会话页的输入框上沿定位。输入框中的测试字符未发送，随后清空。Windows、窄窗口、中文输入法和混合 DPI 实机验收仍待完成；本次未改 Rust 源码，未重复运行 Rust 检查。

0.1.2 将三套装扮的双手移到身体前侧，不再缩小身体区域给双手留出底部空间；按下位移由 8 缩小到 3 个 SVG 坐标单位。构建检查与 16 项回归检查通过，已在本机 DSH 重新启用 0.1.2 并检查水手、睡衣、魔法师装的实际位置。PNG 原文件未改动。

0.1.4 合入远端 `main` 的六款配套手部，补齐基础女仆鱼、长发蓝女仆和克劳德的左右手，同时保留 0.1.2 的手部位置和 0.1.3 的角色名称。构建检查和 16 项回归检查通过，内嵌的十二个 PNG 均与项目素材一致。已在本机 DSH 重新启用 0.1.4 并检查六款角色的显示。

0.2.0 于 2026-11-03 完成本地 Node 回归、客户端语法与构建一致性检查。六款角色在现有 Chrome 中逐一检查，覆盖 100/220 px、375×600 视口、按键回弹、输入框隐藏和重建；可见基线间隙约 1 px。已在本机 DSH 重新安装并启用 0.2.0，认证桥接可查询桌面组件，点击「移到桌面」及直接从窗口边缘拖出均成功启动原生进程并隐藏页面角色。禁用插件后子进程回收，再启用恢复页面角色。原生界面验证了吸附状态、解除吸附和返回操作。桌面 Rust 检查及平台限制见[桌面桥接](desktop-bridge.md)。

0.2.1 于 2026-11-03 完成 45 项本地 Node 回归，以及 Rust 格式、macOS/Windows Clippy、本地回归与 release 构建。macOS 原生面板实测了深色卡片、六款选择菜单、切换角色、暂停、10 px 尺寸步长、演示保留暂停、关闭吸附与恢复位置、桌面选项折叠、关闭按钮和 Escape。返回操作后的宿主状态保留最后设置。协议实进程检查覆盖初始暂停及关闭行、EOF、超长行回收；页面回归覆盖设置返回、刷新去重、延迟响应与存储失败。Windows 界面和混合 DPI 的设置窗定位尚未实机验收。

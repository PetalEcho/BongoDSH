# DSH 插件角色接入

2026-11-03，按用户要求将[制作并接入大肥鱼角色](thread://01a19b7d-d622-74f3-ab0c-1cb443a029ee?hostId=local)会话中的素材存入本项目，再替换 DSH 页面插件中的矢量小鲸鱼。

最初的素材快照取自提交 `1eea77269830dd528991f83ca2dd02deb1635893`，当时存入 24 个 PNG，包括六个角色的线稿和彩稿，以及水手、睡衣、魔法师三套装扮的独立左右手。四份原始生成文档同时保留，当时的文件内容与源提交一致。0.1.4 又合入远端 `main` 的 `0f4e5ac`，替换三套通用彩手并新增另外三款配套双手；现在根目录共有 30 个 PNG。记录中“尚未登记为内置角色”描述的是生成时状态；本次已接入 DSH 页面插件，Rust 桌面渲染器仍使用原有矢量小鲸鱼。

默认角色为基础女仆鱼。点击或右键角色可切换六个彩色角色；选择保存在原有本地设置中，旧版的尺寸、暂停和位置设置会保留。六个角色均分别驱动身体、左手和右手，手部配色与各自服装匹配。

源文件位于根目录 [`assets/`](../assets/)，映射维护在 [`src/characters.js`](../plugins/dsh-bongodsh/src/characters.js)。构建脚本按内容哈希去重，将所需 PNG 原样编码为 data URI 并内嵌到 `client.js`，不再发起图片请求。本机 DSH `0.2.1-rc.5` 尚无新版 `require.asset()` 或插件图片路由，这种打包方式兼容该版本。运行产物包含六张身体和六款独立手部图，无需运行 Rust 程序或额外安装依赖。

来源与许可说明随插件保存在 [ASSETS.md](../plugins/dsh-bongodsh/ASSETS.md)。完整生成过程见[角色上色记录](colored-characters.md)、[大肥鱼线稿](image-generation.md)、[三套换装提示词](fish-outfit-prompts.md)、[趴窝角色记录](prone-lineart-drafts.md)和[角色配套手部](character-hands.md)。

## 实际验证

在 macOS DeepSeek Harness 桌面应用的插件页，通过本地目录导入 `dsh-bongodsh 0.1.1` 并启用。详情页显示一项组件运行中，来源为当前项目插件目录。六个角色均已在真实 DSH 会话中切换并检查显示；聊天页与新会话页均跟随输入框上沿。测试后恢复基础女仆鱼，没有发送测试消息。

0.1.1 的构建、产物一致性和 16 项本地 Node 回归检查通过；内嵌 PNG 与源文件字节一致。当时安装包约 8.6 MB，仅包含运行入口、内嵌素材的客户端、清单、语言文件及说明文档。Windows、窄窗口、中文输入法和混合 DPI 尚未实机验证。本次只修改页面插件、素材和说明，未修改 Rust 源码，因此未重跑 Rust 检查。

随后按用户要求在 0.1.2 中调整手部位置：身体使用完整显示区域，独立双手叠放在身体前侧，按下时仅小幅移动，不在身体下方单独排列。三套带手装扮已在真实 DSH 中检查，原始 PNG 保持不变。

0.1.4 拉取并合入远端 `main` 的配套手部更新，所有十二张手部文件均与 `0f4e5ac` 原样一致。构建检查和 16 项 Node 回归检查通过，打包的十二个独立 PNG 内容与源文件一致。真实 DSH 插件详情页显示 0.1.4 与一项运行中组件，六个角色均已切换并检查新双手。没有改动 Rust 源码，未重跑 Rust 检查。

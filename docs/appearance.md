# 图片与角色设置

## 图层与预览

身体是必需图层，左手和右手可选。程序只绘制用户提供的手部纹理；默认小鲸鱼、单张图片和旧版设置都不再补画通用双手。没有手部时，敲键只让身体轻微压缩。

设置窗口先展示预览和常用操作。宽窗口左右分栏，窄窗口上下排列并允许滚动。身体、左手、右手分别选择文件；拖放目标以选中的图层为准，拖到桌面挂件则始终替换身体。文件选择与演示动作由设置窗口请求主窗口唤醒后执行。

每张图片限制为 16 MB、最长边 4096 像素，接受 PNG、JPEG、WebP。程序根据文件内容识别格式，应用 EXIF 方向，解码时限制内存占用，最多缩小到 1024 × 1024，去掉透明边缘。白色背景不会自动删除。完全透明或无效的图片会显示错误并保留原有角色。

## 本地保存

- macOS：`~/Library/Application Support/BongoDSH/appearance-v2.bin`。
- Windows：`%APPDATA%/BongoDSH/appearance-v2.bin`。
- 验证时可设置绝对目录 `BONGODSH_DATA_DIR`，与正常用户数据隔离。

版本化二进制文件保存当前角色选择以及三个图层的 PNG 字节，不保存原始图片路径。保存时先写同目录临时文件，再替换目标文件。退出前等待后台保存完成；仍未完成的导入不会被静默应用。

没有 v2 文件时，尝试读取同目录 `appearance-v1.bin`。旧版图片迁移为身体，旧版合成双手开关丢弃，原文件不覆盖。无法读取设置时恢复初始小鲸鱼并显示错误；无法保存时明确提示本次选择未落盘。

## 依赖与边界

沿用已有外观实现的 `image 0.25.10` 和 `rfd 0.17.2`。前者只为此功能启用 PNG、JPEG、WebP；后者只在 macOS、Windows 编译，用于系统文件选择器。核心 crate 未增加依赖，也不访问图片或文件系统。

## 验证

本轮在 macOS Apple Silicon 上运行格式、Clippy、本地回归、发布构建和命令行模拟输入。回归覆盖旧版迁移、三层保存与替换、移除手部后重启、损坏记录、坏图片不覆盖已有角色、透明边缘、尺寸限制、JPEG/WebP 解码，以及宽窄窗口布局。

macOS 原生窗口已检查无默认手、分栏预览、文件选择器唤醒与整体背景。Windows x86_64 MSVC 仅做目标编译检查，尚未实机验证文件选择、透明窗口或 DPI。

本地测试文件位于被忽略的 `crates/*/tests/`，不提交或推送。远端 CI 不包含这些本地回归用例。

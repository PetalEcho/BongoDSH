# 从 DSH 拖到桌面

DSH 页面角色可以由插件宿主启动为独立 Rust 窗口。宿主只启动包内或仓库 release 目录的 BongoDSH 可执行文件，使用固定参数和标准输入、输出通信，不建立本地 HTTP 监听。组件构建、打包和页面入口见[插件说明](../plugins/dsh-bongodsh/README.md)。

## 拖动与吸附

拖动的未限制矩形越过页面边缘 16 CSS px 时开始交接；抓住角色最外沿时，在指针朝外进入页面内沿 8 CSS px 范围后交接。这样不依赖 Electron 在指针离开原生窗口后继续发送页面事件。交接时的失焦、指针取消和页面隐藏不终止已启动的桌面请求；真正卸载页面时仍取消未完成的启动。

页面传递角色编号、100–220 的尺寸、暂停状态、两项动作幅度和鼠标在角色矩形内的归一化抓取位置。桌面进程用原生鼠标坐标放置窗口。如果主按钮仍按下，接续跟随鼠标，松开后吸附附近程序窗口的边缘。启动时已经松开也会在当前鼠标位置尝试吸附。浏览器 CSS 坐标不转换成屏幕坐标，避免浏览器缩放和 Windows 显示缩放混用。

吸附范围为 32 个逻辑点，可见轮廓与窗口边缘相距 2 个逻辑点。只选择最前方的相交窗口，记录边缘和相对位置。吸附后每 200 毫秒查询窗口几何，跟随目标移动或缩放。目标关闭、隐藏或最小化后解除吸附；再次拖动会解除旧目标，松开后重新选择目标。没有吸附且没有拖动时不持续查询窗口。

右键桌面角色打开独立圆角设置卡片，避免菜单被小角色窗口裁切。卡片与页面使用相同的深浅色系、控件顺序和常用操作：五款角色、暂停、100–220 px 大小、独立手部和身体幅度及恢复位置。桌面定位开关控制窗口吸附，恢复位置回到本轮拖出的初始落点，不读取其他程序的输入框。全局键盘和置顶放在默认折叠的桌面选项中。两项幅度均为 0–200%，默认 100%，0% 只关闭对应部位的动作；设置导航按键不触发角色动作。

关闭按钮或 Escape 只关闭设置；“返回 DSH”关闭桌面角色。页面每秒检查桌面进程状态，接收角色、大小、暂停和两项幅度，退出后恢复页面角色。页面隐藏时暂停查询，重新可见后继续。刷新页面保留已就绪的桌面进程；标准输入断开、宿主关闭或禁用宿主插件会回收桌面进程。

五款角色使用与页面相同的原图和手部位置。Rust 将 PNG 解码为纹理，按 alpha 大于等于 16 的可见矩形计算显示尺寸，保留独立身体、左手和右手图层。身体与双手共用 248/300 的底部基线，双手放在脸部两侧。不会写回或修改 PNG。

## 进程协议

```text
bongodsh --detached <character-id> <size> [--grab <grab-x> <grab-y>] [--paused <true|false>]
  [--hand-amplitude <0..200>] [--body-amplitude <0..200>]
```

`character-id` 只能是 `blue-maid`、`sailor`、`pajamas`、`wizard`、`orange-bride`。尺寸必须为 100–220 的整数；抓取位置必须在 0–1 内，省略时为 `(0.5, 0.5)`。暂停参数只能为 `true` 或 `false`，省略为 `false`。手部和身体幅度分别为 0–200 的整数百分比，省略时各为 100。可选参数顺序不限，各使用一次。不接收自定义文件路径、命令或输入文本。

窗口准备显示后，标准输出写入并刷新一行：

```json
{"event":"ready"}
```

随后首次发送设置快照，并在角色、尺寸、暂停或任一幅度变化时发送新快照，退出前刷新最后的变化：

```json
{"event":"settings","character":"blue-maid","size":160,"paused":false,"handAmplitude":100,"bodyAmplitude":100}
```

宿主逐行解析有界 JSON 事件并校验角色、整数尺寸、布尔暂停值及两项整数幅度。兼容旧版四字段事件，两项幅度补为 100；新版事件必须同时包含两个幅度字段。有效快照附带唯一版本标识，进程退出后仍保留最后值。页面只应用未接收过的版本，将设置和已应用版本分别写入本地存储，避免刷新时旧桌面快照覆盖后续页面设置。桌面吸附开关与页面的 `docked`、`x`、`y` 分开处理。

宿主只能发送以下固定控制行，结尾可以是 LF 或 CRLF：

```json
{"type":"close"}
```

其他短行忽略。单行超过 128 字节、读取失败或 EOF 都关闭桌面窗口。错误写入标准错误；异常退出由宿主处理。协议没有持续传输屏幕坐标的命令，续拖直接读取原生鼠标，页面失焦后不依赖网页继续发送事件。

## 平台与输入边界

macOS 使用 AppKit 的窗口和鼠标位置，以及 Core Graphics 的可见窗口编号、进程编号和边界。窗口保持 accessory 策略，不新增 Dock 图标。Windows 使用 `GetCursorPos`、`EnumWindows`、DWM 边界与挂件的 DPI，使用物理像素计算位置。两端均保留负屏幕坐标，并将窗口限制在最近的显示器可用区域内。

窗口探测不读取标题、辅助功能文本、输入框内容或截图，也不申请系统权限。吸附对象是其他程序窗口的边缘；没有读取其他程序的输入框位置。原生 FFI 仅在 `platform/macos.rs`、`platform/windows.rs` 与原有全局输入平台模块放行，每处说明对象和指针生命周期。

首次拖出仅响应角色窗口内的按键。在右键设置中主动启用全局键盘后，桌面进程将输入模式保存在本机；重启 DSH、独立重启或重新拖出都会恢复选择。该设置由原生进程读取，不由页面或桥接传递。暂停时不启动监听；缺少权限或监听失败时保留全局模式选择并暂用窗口输入。macOS 的输入监控授权流程沿用[全局键盘说明](global-keyboard.md)，恢复设置不会自动申请或更改系统权限。

## 构建成本

`image` 仅声明 PNG 解码功能；`raw-window-handle` 取得 eframe 创建的原生窗口。macOS 直接声明依赖树中已有的 `core-foundation`、`core-graphics`、`objc2`、`objc2-app-kit`、`objc2-foundation`，启用需要的窗口 API。Windows 复用 `windows-sys`，增加 DWM 和 DPI 功能。没有新增网络服务或异步运行时。五款图片内嵌于桌面二进制，图片变更后须重新构建桌面程序。

Windows 交叉编译通过不能代替实机运行。混合 DPI、多显示器跨屏拖动、macOS Spaces 和各程序窗口遮挡情况需分别实机验收。

## 本轮验证

0.2.0 于 2026-11-03 在 macOS Apple Silicon 完成格式检查、工作区 Clippy、8 项本地回归、release 构建和命令行演示。真实桌面子进程分别接受关闭行、EOF 和超长行，均在输出 ready 后正常退出，标准错误为空。沙箱内的系统窗口服务连接受限，运行验证在获准访问 macOS 桌面的环境中完成，没有更改系统权限。

本地回归覆盖命令参数范围、吸附后跟随目标、目标消失、前窗遮挡、两倍 DPI 几何、负屏幕坐标和六款图片的显示边界，保存在忽略的 `crates/bongodsh-app/tests/`，不随仓库提交。Windows x86_64 MSVC 目标编译和 Clippy 通过；主按钮互换按系统设置查询物理鼠标按键。尚未进行 Windows 实机或混合 DPI 跨屏拖动验收。

macOS 原生界面已显示精修彩稿和分离双手，实际拖动后设置显示已吸附窗口；解除吸附后状态更新，点击“返回 DSH”后独立进程退出。真实 DSH 边缘拖出后，页面角色隐藏，包内进程接收到角色、尺寸和归一化抓取位置；禁用插件后进程回收，再启用后恢复页面角色。窗口移动跟随的几何规则有本地回归覆盖，跨程序窗口移动、Spaces 和混合 DPI 的完整人工验收仍待补充。

0.2.1 补齐设置卡片与角色、尺寸、暂停同步。macOS 实测角色切换、暂停、10 px 尺寸步长、演示保留暂停、关闭吸附与恢复位置、折叠选项、关闭按钮和 Escape；退出后的宿主状态保留最后设置。真实进程验证了初始暂停状态及三种管道退出情况，45 项 Node 回归覆盖返回同步、过期响应、刷新与存储失败。原生检查包含实际 egui 指针拖动，macOS/Windows Clippy、本地回归和 release 构建通过。已更新本机插件并由真实 DSH 启动新版组件。Windows 界面及混合 DPI 的设置窗定位尚未实机验收。

0.2.2 新增独立手部和身体幅度，移除产品中的演示入口。57 项 Node 回归、18 项桌面桥接回归、Rust 格式、macOS/Windows Clippy、release 构建和插件产物检查通过。覆盖 0/100/200% 独立动作、六款角色的画布与脸部边界、输入框间距、旧设置迁移、幅度同步及延迟响应保护。macOS 实测两个面板的滑块、0/200% 独立取值、原生设置回传和返回后保留；DSH 重启后仍保留幅度，并已启动包内新版组件。真实子进程验证默认幅度、极值参数及三种管道退出情况。Windows 界面和混合 DPI 尚未实机验收。

0.2.3 将输入模式保存在原生本机配置中。新增 9 项偏好回归覆盖缺失、损坏、读取失败、全局与窗口模式往返、暂停、原子替换失败清理及并发读取；工作区测试、Rust 格式、macOS/Windows Clippy、release 构建和命令行模拟均通过。macOS 已通过真实 DSH 验证：开启全局键盘后返回页面再移到桌面，以及退出 DSH 后重新启动并移到桌面，均自动选中全局模式，配置文件没有被重启或退出改写。实测期间系统暂时限制监听，保存的全局模式仍保留；没有更改系统权限。已更新本机 0.2.3 组件，真实子进程的关闭行、EOF 和超长行回收检查通过。Windows 界面和多显示器完整验收仍待实机验证。

# BongoDSH DSH 插件

直接在 DeepSeek Harness 页面内显示大肥鱼角色。页面模式不需要 Rust 或系统键盘权限。默认使用基础女仆鱼，设置中可切换六个彩色角色。安装桌面组件后，可以拖出 DSH 并吸附其他程序窗口。

## 安装

当前版本为 0.2.2，按本机 DSH `0.2.1-rc.5` 的客户端加载和认证连接接口实现，最低版本声明为 `>=0.2.1-rc.5`。历次验证记录见下文。

桌面版打开「插件 → 添加插件」，填写本仓库 `plugins/dsh-bongodsh` 的绝对目录路径，安装后点击「立即启用」。本地目录安装显示为 `link:` 来源，需要保留该目录。

从仓库根目录安装本地插件：

```sh
dsh plugin --profile web add ./plugins/dsh-bongodsh
```

也可以安装打包文件：

```sh
dsh plugin --profile web add /absolute/path/dsh-bongodsh-0.2.2.tgz
```

`web` 是 Web profile。若桌面版使用其他 profile，在 DSH 插件管理页确认对应 profile 后安装；不直接修改桌面应用的内部文件。没有启用插件热加载时，安装后重启对应 DSH 实例并刷新页面。

在插件管理中禁用或移除 `dsh-bongodsh`，即可卸载角色、页面监听和布局观察器。用户设置保留在该站点的本地存储中。

## 使用

- 默认停在可见输入框上沿，找不到输入框时停靠页面右下方。布局改变后重新定位。
- 按 PNG 的可见轮廓定位，常规窗口下与输入框留 1 CSS px；六款双手分别设置大小和位置，避开眼睛与嘴巴。
- 当前页面的字母、数字、标点等物理按键驱动角色动作。六个角色均配有与各自服装匹配的独立双手，叠放在身体前侧，交替轻压。长按不会重复敲击，多键保持时分别等待松开。
- 拖动角色自由放置，靠近输入框右上方后松手可重新吸附。点击或右键打开设置，键盘可用 Tab 聚焦角色、Enter 打开设置、Escape 关闭。
- 将角色拖出 DSH 窗口，或点击设置中的「移到桌面」，可交给 Rust 桌面窗口。桌面角色靠近其他程序窗口边缘松手后吸附并跟随移动；右键打开设置，可解除吸附或返回 DSH。
- 设置包含六个角色切换、暂停、跟随输入框、100–220 px 尺寸、独立手部和身体幅度及恢复位置。两项幅度范围均为 0–200%，默认 100%，0% 只关闭对应部位的动作。刷新页面后保留设置，同一站点的其他标签页会同步更新。升级时保留原有设置，新增幅度默认为 100%。
- 桌面右键设置使用相同的紧凑卡片布局，支持六款角色、暂停、大小、独立手部和身体幅度及恢复位置。桌面定位开关为「吸附窗口」，恢复位置回到本轮拖出的初始落点。角色、大小、暂停和两项幅度同步回 DSH；页面的输入框跟随与自由位置保留。全局键盘和置顶选项收在「桌面选项」中。
- 关闭按钮或 Escape 只收起设置；「返回 DSH」关闭桌面角色并恢复页面显示。
- 窗口失焦、页面隐藏、暂停、卸载和重新加载时清空按住状态。启用系统「减少动态效果」时使用直接的按住姿态。

插件只读取 `KeyboardEvent.code`、连发标记和快捷键修饰状态。不读取 `key`、输入框内容或输入法组合文字，不保存按键记录。PNG 内嵌在客户端包内，不发起图片请求，也不上传数据。密码框不触发动作，Ctrl / Command / Alt 快捷键被过滤，AltGr 输入可正常反馈。中文输入法只按实际物理按键反馈，不根据候选词或上屏字数补造动画。

## 范围

页面角色不在 DSH 失焦时监听其他应用。拖出后默认只响应桌面角色窗口内按键，跨应用反馈需在原生设置中主动开启全局键盘。当前不包含原生输入框定位、任务完成提醒、声音、自定义素材或系统托盘。

页面定位仅使用 DSH 显式的 `[data-composer-card]` 标记与 CSS 像素，不推断屏幕物理坐标。该标记属于上游实现细节；若未来 DSH 改名，角色会退回页面边缘，需更新适配。页面内 iframe 的按键不纳入当前范围。

## 桌面组件

本地目录安装时，在仓库根目录运行：

```sh
cargo build --workspace --release --locked
```

插件宿主自动查找仓库的 `target/release/bongodsh`，Windows 为 `bongodsh.exe`。若需要把桌面组件包含在安装包里，在当前平台执行：

```sh
cd plugins/dsh-bongodsh
mkdir -p dist
npm run prepare:native
npm pack --pack-destination dist
```

`prepare:native` 构建当前平台的 release 程序，复制到忽略的 `native/<platform>-<arch>/`；该目录只进入本地安装包，不提交 Git。macOS 使用独立标识的 `BongoDSH Companion.app`，避免与已安装的旧版同名应用混淆。macOS 包不能作为 Windows 桌面组件使用，反之亦然。没有桌面二进制时，页面功能仍可用，并提示完成桌面设置。

插件复用 DSH 认证连接的 owner 专属精确路由。宿主只启动固定路径二进制，不接受页面传入的文件路径或命令，不建立额外 HTTP 监听。鼠标接续由原生坐标完成，页面只传归一化抓取位置。桌面窗口 ready 后隐藏页面角色；窗口退出后恢复。临时连接失败保持当前显示状态并重试，避免重复角色。刷新页面不关闭已经就绪的桌面角色；禁用宿主插件、DSH 退出或父管道断开会回收进程。协议和平台边界见[桌面桥接](../../docs/desktop-bridge.md)。

## 开发与验证

需要 Node.js 22.19 或更高版本。无需 `npm install`，构建工具只使用 Node 标准库。

```sh
cd plugins/dsh-bongodsh
npm run build
npm run check
npm run preview
```

预览命令输出仅绑定 `127.0.0.1` 的随机端口。手动打开输出的网址；脚本不启动浏览器。预览页加载与安装包相同的 `client.js`，可以检查按键、拖动、设置、输入框重建和插件加载/卸载。它模拟客户端生命周期，不等同于 DSH 安装验收。

`src/model.js` 独立实现与 Rust 核心一致的按键规则和弹簧参数；浏览器不加载 Rust 二进制。`src/characters.js` 登记彩稿和手部布局，`src/art.js` 使用 SVG 图层显示 PNG 并驱动动作。构建脚本只读解析 alpha 大于等于 16 的可见边界，按内容哈希去重，将 PNG 原样内嵌到客户端。`client.js` 随源码保留，安装不运行构建脚本。修改素材后运行 `npm run build`、`npm run check`，并重新构建桌面组件。

打包时先创建 `dist` 目录，然后运行：

```sh
npm pack --pack-destination dist
```

包内包含宿主桥接、客户端产物、十二个内嵌 PNG 资源、bundle patch、语言信息、本文和素材来源说明。如果已运行 `prepare:native`，还包含当前平台的桌面可执行文件。预览、源文件、线稿和测试不进入安装包。代码许可证待项目所有者决定，当前以 `UNLICENSED`、`private` 声明阻止意外公开发布。

本地回归用例位于忽略的 `tests/`，有这些文件时运行 `node --test tests/*.test.mjs`。CI 检查语法、产物与源码一致性及打包清单，不代表执行了未提交的本地回归用例。
